# Expense Tracker Web Application

A full-featured Personal Expense Tracker web application developed with **Python Flask**, **SQLite**, and **Bootstrap 5**.

## Features

- **User Authentication**: Secure user registration and login (User ID / Username / Email / Phone and Password).
- **Dashboard Overview**: Track today's total spending, current month total, and view recent transactions.
- **Expense Management**: Add, view, edit, and delete daily expenses with category tagging and notes.
- **Categorized Spending**: Categorize expenses by Food, Travel, Rent, Utilities, Entertainment, Shopping, Healthcare, Education, and more.
- **Monthly Analytics & Reports**: Visual breakdown and charts for monthly expenses by category using Chart.js.
- **User-Specific Isolation**: Each registered user has their own private expense records.

## Technology Stack

- **Backend**: Python, Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5, FontAwesome, Chart.js

## Getting Started

### 1. Prerequisites
- Python 3.8+ installed

### 2. Setup Virtual Environment
```bash
python -m venv venv
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```
Open your browser and navigate to `http://127.0.0.1:5000`
